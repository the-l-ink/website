---
title: The Link
description: Composable bidirectional event routing across application boundaries.
---

The Link gives applications one small communication model across HTTP, local
processes, Workers, frames, and tabs. Application code publishes named events
through an outbound tunnel and handles received events through an inbound
tunnel. Adapters carry that contract across boundaries without redefining it.

```ts
import { Tunnel } from "@the-link/core"

const tunnel = new Tunnel()

tunnel.subscribe("sum", (left: number, right: number) => left + right)

const total = await tunnel.publishFirst<number>("sum", 20, 22)

console.log(total) // 42
```

## One model, specialized adapters

`@the-link/core` owns the routing primitives. The remaining packages adapt those
primitives to concrete environments:

| Package | Boundary |
| --- | --- |
| `@the-link/http` | HTTP requests and WebSocket connections |
| `@the-link/ipc` | Process channels, Unix sockets, and Windows named pipes |
| `@the-link/worker` | Browser and Node.js Workers |
| `@the-link/frame` | Browser Windows and iframes |
| `@the-link/tab` | Same-origin browser contexts through `BroadcastChannel` |
| `@the-link/messagepack` | Optional type-preserving byte serialization |
| `@the-link/react` | Core tunnel and property state inside React |

The adapters do not introduce another event vocabulary. A Link remains a Link,
and every routing relationship can be removed through the cleanup function
returned when it is created.

<Callout title="Transport-neutral by design">
  Core does not know whether an event crosses HTTP, a process channel, a Worker,
  a browser context, or no transport at all.
</Callout>

## The routing lifecycle

Every `Tunnel.publish()` follows the same ordered lifecycle:

<Steps>
  <Step>
    ### Intercept

    Prefix-matched interceptors transform or reject the published values.
  </Step>
  <Step>
    ### Subscribe

    Handlers registered for the exact event run and contribute results.
  </Step>
  <Step>
    ### Forward

    Prefix-matched forwarding rules route the event into other tunnels.
  </Step>
  <Step>
    ### Finalize

    Prefix-matched finalizers transform the aggregated results.
  </Step>
</Steps>
