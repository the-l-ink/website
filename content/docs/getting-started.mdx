The smallest useful setup needs only `@the-link/core`. Add an adapter when a
route must cross a concrete boundary.

## Requirements

- A modern JavaScript runtime with ECMAScript modules
- TypeScript when you want the published declarations and decorator metadata
- React 19.2 or later only when using `@the-link/react`
- A browser and Hono-compatible runtime for the HTTP adapter
- Node.js for the IPC Process and Socket adapters
- A compatible browser or Node.js runtime for Worker adapters

## Route an event

Create a tunnel, register an exact-event handler, then publish through it.

```ts
import { Tunnel } from "@the-link/core"

const commands = new Tunnel()

const unsubscribe = commands.subscribe("greet", (name: string) => {
  return `Hello ${name}`
})

const greeting = await commands.publishFirst<string>("greet", "World")

console.log(greeting) // Hello World

unsubscribe()
```

`subscribe()` returns its cleanup function. Cleanup belongs beside the code that
created the relationship; no separate listener registry is required.

## Connect two links

A `TheLink` owns two tunnels:

- `$outbound` carries events toward an adapter or another routing layer.
- `$inbound` carries events received from an adapter or another routing layer.

```ts
import { TheLink } from "@the-link/core"

const application = new TheLink()
const account = new TheLink()

account.$inbound.subscribe("profile", () => ({ name: "Example" }))

const disconnect = application.connectTo(account)
const profile = await application.$outbound.publishFirst<{ name: string }>("profile")

disconnect()
```

Use prefixes to mount a link beneath a namespace:

```ts
const disconnect = application.connectTo(account, "", "account:")

await application.$outbound.publish("account:profile")
```

## Cross a boundary

Install the adapter that owns the boundary. For example, a browser publishes to
a Hono server through the HTTP package:

```sh
npm install @the-link/http
```

The server exposes the route:

```ts
import { HttpServer } from "@the-link/http/server"

const server = new HttpServer()

server.$inbound.subscribe("sum", (left: number, right: number) => left + right)
server.prepareConnection()

export default server.app
```

The browser addresses the same route:

```ts
import { HttpClient } from "@the-link/http/client"

const client = new HttpClient("https://api.example.com/events")
const [total] = await client.$outbound.publish<[number]>("sum", 20, 22)
```

Read [HTTP](./packages/http.mdx) for WebSocket subscriptions and runtime
integration details.
