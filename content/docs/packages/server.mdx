---
title: Server
description: Hono HTTP routes and independent WebSocket links for connected clients.
---

`@the-link/server` adapts the Core Link contract to Hono. `ServerLink` owns the
Hono application, routes browser publications through its inbound tunnel, and
represents each accepted WebSocket as an independent `SocketLink`.

## Install

```sh
npm install @the-link/server
```

## HTTP route

```ts
import { ServerLink } from "@the-link/server"

const server = new ServerLink()

server.$inbound.subscribe("sum", (left: number, right: number) => {
  return left + right
})

server.prepareConnection()

export default server.app
```

`prepareConnection()` always registers `POST /publish`. Mount `server.app` at the
same base URL given to the browser's `ClientLink`.

An optional Hono configuration object can be passed to the constructor.

## WebSocket route

Pass the `upgradeWebSocket` function from the chosen Hono runtime adapter to also
register `GET /subscribe`:

```ts
server.prepareConnection(upgradeWebSocket)

server.onSubscribe<{ token: string }>(socket => {
  console.log(socket.payload.token)

  socket.$inbound.subscribe("presence:update", status => {
    console.log(status)
  })

  socket.autoJoin(server)

  return { userId: "user-42" }
})
```

The Server Socket Link's `payload` is supplied by the client. The first value
returned from subscription handlers becomes the response exposed as the Client
Socket Link's `payload`.

## Address one client

Each accepted connection has its own Link:

```ts
server.onSubscribe(socket => {
  socket.$outbound.publish("notification", {
    title: "Connected",
  })
})
```

Active sockets are stored in `server.sockets` by connection UUID. Use
`socket.unsubscribe(code?, reason?)` to close from the server. `autoJoin()` binds
another Link until the socket closes.

## Errors and debugging

Detailed handler errors are hidden from HTTP clients by default. Enable them
only in a controlled development environment:

```ts
server.enableDebugging()
server.disableDebugging()
```

## Custom codecs

```ts
server.setSerialize(serialize)
server.setDeserialize(deserialize)
```

The paired Client Link must use compatible functions.

## Exports

```ts
import { ServerLink, SocketLink } from "@the-link/server"
```
