that same contract into a particular runtime or transport.

## Selection guide

| Need | Package |
| --- | --- |
| In-memory event routing | `@the-link/core` |
| Browser request-response to a server | `@the-link/http` |
| Long-lived browser/server traffic | `@the-link/http` |
| Parent/child Node.js messaging | `@the-link/ipc/process` |
| Unix socket or Windows named-pipe messaging | `@the-link/ipc/socket-client` + `@the-link/ipc/socket-server` |
| Browser or Node.js Worker messaging | `@the-link/worker` |
| Parent/iframe messaging | `@the-link/frame` |
| Same-origin tab or window broadcasts | `@the-link/tab` |
| Type-preserving bytes | `@the-link/messagepack` |
| Render Tunnel or Property state | `@the-link/react` |

Every package uses named exports. Subpaths distinguish adapters only when one
domain has multiple concrete runtime roles.

```ts
import { TheLink, Tunnel, Property } from "@the-link/core"
import { HttpClient } from "@the-link/http/client"
import { HttpServer } from "@the-link/http/server"
import { ProcessLink } from "@the-link/ipc/process"
import { SocketClient } from "@the-link/ipc/socket-client"
import { SocketServer } from "@the-link/ipc/socket-server"
import { BrowserWorker } from "@the-link/worker/browser"
import { NodeWorker } from "@the-link/worker/node"
import { FrameLink } from "@the-link/frame"
import { TabLink } from "@the-link/tab"
import { deserialize, serialize } from "@the-link/messagepack"
import { ReactTunnel, useProperty } from "@the-link/react"
```
