that same contract into a particular runtime or transport.

## Selection guide

| Need | Package |
| --- | --- |
| In-memory event routing | `@the-link/core` |
| Browser request-response to a server | `@the-link/client` + `@the-link/server` |
| Long-lived browser/server traffic | `@the-link/client` + `@the-link/server` |
| Render Tunnel or Property state | `@the-link/react` |
| Parent/child Node.js messaging | `@the-link/process` |
| Same-origin tab or window messaging | `@the-link/tab` |

All packages use named root exports. Only Core decorators are intentionally
isolated behind subpath exports.

```ts
import { TheLink, Tunnel, Property } from "@the-link/core"
import { ClientLink } from "@the-link/client"
import { ServerLink } from "@the-link/server"
import { ReactTunnel, useProperty } from "@the-link/react"
import { ProcessLink } from "@the-link/process"
import { TabLink } from "@the-link/tab"
```
