---
title: Process
description: Carry the Link event envelope between Node.js parent and child processes.
---

`@the-link/process` maps outbound events to `process.send()` and incoming
messages to the inbound tunnel. Messages use the envelope `[event, ...values]`.

## Install

```sh
npm install @the-link/process
```

## Parent process

Spawn the child with an IPC channel, then pass the `ChildProcess` to the Link:

```ts
import { fork } from "node:child_process"
import { ProcessLink } from "@the-link/process"

const worker = fork(new URL("./worker.js", import.meta.url), {
  stdio: ["inherit", "inherit", "inherit", "ipc"],
})

const link = new ProcessLink(worker)

link.$inbound.subscribe("job:done", result => {
  console.log(result)
})

await link.$outbound.publish("job:start", { id: 42 })
```

## Child process

Inside the child, the default target is the current Node.js process:

```ts
import { ProcessLink } from "@the-link/process"

const link = new ProcessLink()

link.$inbound.subscribe("job:start", async job => {
  await link.$outbound.publish("job:done", {
    id: job.id,
    status: "complete",
  })
})
```

Construction fails when the selected target has no active IPC `send` function.
Messages use Node's process serialization directly; the Core byte codec is not
applied.

## Export

```ts
import { ProcessLink } from "@the-link/process"
```
